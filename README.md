### [PlacementGPT](https://github.com/ritik-sa0201) &nbsp;·&nbsp; Multi-Agent Recruitment Outreach Platform

> Automates end-to-end recruiter outreach — job portal parsing, recruiter discovery, company research, and personalized email delivery.

- Architected a **5-agent LangGraph pipeline** covering discovery → research → generation → delivery
- Built a **hybrid retrieval system** (FAISS dense search + BM25 sparse retrieval) with cross-encoder reranking, improving top-k precision over single-method semantic search
- Full observability via **LangSmith** for distributed tracing, cutting average debugging time by 20%
- Containerized with **Docker**, deployed to **AWS (EC2 + S3)** via **GitHub Actions** CI/CD

`FastAPI` `LangGraph` `LangSmith` `RAGAS` `Ollama (Llama 3.2)` `FAISS` `BM25` `Docker` `AWS`
